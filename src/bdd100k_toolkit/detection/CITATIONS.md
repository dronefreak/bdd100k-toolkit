# Citations for the detection models

If you use one of the detection models of this project, please cite its paper (or the
Ultralytics software entry where no paper exists), and the BDD100K dataset paper
(see the main README).

| Model | Cite |
|---|---|
| YOLOv8n, YOLOv8s | Ultralytics YOLOv8 (software) |
| YOLOv9t | YOLOv9 paper |
| YOLOv10n, YOLOv10s | YOLOv10 paper |
| YOLO11n, YOLO11s | Ultralytics YOLO11 (software) |
| YOLO26n, YOLO26s | YOLO26 paper |
| RF-DETR Nano | RF-DETR paper |
